# FinBERTx - Autonomous CFD Trading Workstation 🚀
### منصة وبوت التداول الذاتي والتراكمي لوسيط Capital.com مع نموذج ProsusAI/finbert وتحليل الفريمات المتعددة

---

## 📌 نبذة عامة عن المشروع (Overview)
**FinBERTx** هو نظام تداول مالي حقيقي ومؤتمت بالكامل (Production-Ready) مصمم للتداول المباشر في أسواق العملات وعقود الفروقات (CFDs) عبر وسيط **Capital.com** العالمي. 

يتميز النظام بعدم اعتماده على مؤشرات فنية تقليدية متأخرة، بل يدمج نموذج معالجة اللغة الطبيعية المالي **`ProsusAI/finbert`** (يعمل بكفاءة فائقة على المعالج **CPU**) مع **نظام تحليل الفريمات المتعددة (Multi-Timeframe Analysis)** لستة فريمات زمنية (`M5`, `M15`, `M30`, `H1`, `H4`, `D1`) لتوليد **قرارات تداول أكيدة ومؤكدة**.

---

## 🌟 الميزات الجوهرية (Core Features)

1. **تداول حقيقي مباشر على وسيط Capital.com:**
   - ربط كامل مع واجهات Capital.com REST API للمصادقة واستخراج رموز الجلسة `CST` و `X-SECURITY-TOKEN`.
   - التبديل الفوري بين الحساب التجريبي (`DEMO`) والحساب الحقيقي (`LIVE`).
   - استخدام أعلى رافعة مالية متاحة **`1:100`** لتعظيم كفاءة الهامش.

2. **محرك التداول التراكمي (Compounding Wealth Engine):**
   - استعلام لحظي عن الرصيد الفعلي وحقوق الملكية (`Equity`) قبل فتح كل صفقة.
   - احتساب حجم اللوت التراكمي بنسبة **3%** من الرصيد الحقيقي.
   - **النمو الأسي:** إعادة استثمار الأرباح تلقائياً وتكبير حجم الصفقات مع نمو رأس المال، وتقليص حجم العقود آلياً عند التراجع لحماية المحفظة.

3. **إلغاء المعايير الثابتة وإدارة مخاطر ديناميكية:**
   - تم إلغاء النقاط الثابتة للوقف وجني الأرباح.
   - مستويات وقف الخسارة وجني الأرباح تُحسب **ديناميكياً** وفق تقلبات السوق اللحظية ونسبة عائد لمخاطرة **`1:2.4 R:R`**.

4. **التحليل المتعدد الفريمات (MTF - قرارات أكيدة):**
   - فحص متزامن لـ 6 فريمات: `M5` (زخم الدخول)، `M15` (التوقيت)، `M30` (التأكيد)، `H1` (الاتجاه الأساسي)، `H4` (الهيكل العام)، و `D1` (الاتجاه اليومي).
   - لا تنفذ أي صفقة إلا عند توافق **4 فريمات على الأقل (أكثر من 66%)** مع إشارة FinBERT لمنع الإشارات الكاذبة.

5. **تغطية 28 زوج عملات CFD بالكامل:**
   - الأزواج الرئيسية (EURUSD, GBPUSD, USDJPY, USDCHF, USDCAD, AUDUSD, NZDUSD).
   - أزواج اليورو والباوند والين والعملات السلعية المتقاطعة (Crosses).

6. **توليد رابط عام تلقائي للواجهة على سيرفرات Linux VPS:**
   - عند تشغيل البوت على سيرفرك الخاص، يقوم تلقائياً بإنشاء نفق سحابي آمن وتوليد **رابط عام فوري (Public HTTPS URL)** للواجهة الرسومية وبثه إلى تيلجرام دون الحاجة لشراء دومين أو شهادات SSL!

7. **بوت وقناة تيلجرام التفاعلية:**
   - 18 أمراً نصياً مباشراً مسجلة في `BotFather`.
   - بث مباشر وفوري للصفقات المفتوحة، التعديلات، وتقارير الأداء في القناة.

## 📋 متطلبات التشغيل (Prerequisites)
- خادم **Linux VPS** (Ubuntu 22.04 / 24.04 أو Debian 11/12).
- بايثون 3.10+ مع بيئة `python3-venv` و `python3-pip`.
- Node.js 18+ لتشغيل خادم الواجهة الرسومية.

### الخطوة 3: التثبيت التلقائي والتشغيل في الخلفية 24/7 (بدون systemd)
نفّذ سكربت التثبيت التلقائي المتوافق مع كافة خوادم VPS (LXC / OpenVZ / Alpine / Ubuntu / Debian):
```bash
chmod +x *.sh
./setup_vps.sh
```
يقوم هذا السكربت آلياً بـ:
1. تثبيت حزم بايثون و PyTorch CPU ونموذج FinBERT.
2. تثبيت أداة توليد الرابط العام التلقائي (`cloudflared`).
3. إعداد التشغيل التلقائي عند إقلاع السيرفر عبر `Crontab (@reboot)` بدون الحاجة إطلاقاً لـ systemd.
4. إطلاق البوت وخادم الواجهة في الخلفية فورياً وتوليد الرابط العام وبثه لتيلجرام.

### الخطوة 4: إدارة البوت في الخلفية (أوامر سريعة ومباشرة)
- **فحص الحالة ومتابعة السجلات الحية مباشرة:**
  ```bash
  ./status_background.sh
  ```
- **تشغيل البوت في الخلفية:**
  ```bash
  ./start_background.sh
  ```
- **إيقاف البوت في أي وقت:**
  ```bash
  ./stop_background.sh
  ```

*(خيار إضافي): إذا كنت تفضل استخدام أداة PM2 الشهيرة:*
```bash
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 status
```

## 🤖 أوامر بوت تيلجرام المباشرة (@capital_ai_x_bot)

| الأمر | الوظيفة |
| :--- | :--- |
| `/start` | تشغيل البوت وعرض لوحة التحكم والأوامر |
| `/balance` | استعلام لحظي عن الرصيد الفعلي، حقوق الملكية، وحجم العقد التراكمي |
| `/compound` | استعراض ومحاكاة التداول التراكمي ونمو رأس المال |
| `/multi_tf EURUSD` | فحص وتأكيد القرار عبر جميع الفريمات (M5 إلى D1) لقرار أكيد |
| `/pairs` | استعراض قائمة أزواج الـ CFDs الـ 28 المراقبة بالكامل |
| `/fmp` | استعراض أحداث المفكرة الاقتصادية وأسعار الصرف من مزود FMP |
| `/status` | فحص حالة النظام، السوق، والرافعة المالية (1:100) |
| `/positions` | عرض الصفقات المفتوحة الحالية وأرباحها اللحظية |
| `/close_all` | 🚨 إغلاق جميع الصفقات المفتوحة فوراً بنقرة أمر |
| `/sentiment` | قراءة مشاعر FinBERT اللحظية لأهم الأزواج |
| `/macro` | مؤشرات الماكرو اللحظية من البنك الفيدرالي FRED |
| `/backtest` | تشغيل باكتيست فوري وبثه في القناة |
| `/mode_demo` | التحويل إلى الحساب التجريبي Demo |
| `/mode_live` | التحويل إلى الحساب الحقيقي Live |
| `/market_status` | فحص حالة افتتاح أو إغلاق السوق |
| `/trade_buy EURUSD` | فتح أمر شراء تراكمي فوري برافعة 1:100 |
| `/trade_sell EURUSD` | فتح أمر بيع تراكمي فوري برافعة 1:100 |
| `/help` | دليل الأوامر الشامل والتعليمات |
